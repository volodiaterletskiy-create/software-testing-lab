# Практична робота №3: Автоматизоване тестування вебсайту за допомогою ШІ та Playwright

**Посилання на вебсайт, який тестували:** https://www.housebrand.com/ua/uk/

**Використаний інструмент ШІ:** Google Gemini

## Опис трьох автоматизованих перевірок
1. **Відкриття сайту та перевірка доступності:** перехід на головну сторінку інтернет-магазину House Brand та перевірка HTTP-статусу відповіді (менше 400).
2. **Перевірка заголовка сторінки:** підтвердження того, що заголовок вкладки (`title`) містить назву бренду `House`.
3. **Перевірка навігації по каталогу:** закриття банера cookie, перехід до категорії «Жінка» та відкриття розділу «Міжсезонний розпродаж».

## Інструкція із запуску тесту
1. Встановіть Node.js та відкрийте папку проєкту в терміналі.
2. Встановіть залежності та браузери Playwright:
   ```bash
   npm init -y
   npm install -D @playwright/test
   npx playwright install
   ```
3. Запустіть тест із відображенням вікна браузера:
   ```bash
   npx playwright test house.spec.js --headed
   ```
